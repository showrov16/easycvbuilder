For the site owner. Nothing here is saved, and nothing goes live until you save it on GitHub with your own sign-in.

Copy the line, open the file on GitHub, add it as a new line at the bottom, then press Commit changes. It appears on the Experiences page after GitHub Pages updates, usually within a minute or two.
